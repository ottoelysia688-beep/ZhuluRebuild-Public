# 逐鹿 ZhuluRebuild

东方王朝政治模拟 × 游牧双体系的大型玩法重构 Mod（WorldBox v0.51.2 / build 549）。

## 核心玩法

- **五等爵位制 + 天命体系** —— 受命于天，天命庇佑
- **官制 / 科举 / 党争** —— 官员任命、科举取士、朝堂党争与派系演化
- **谥法与中文命名** —— 帝王谥号、人物与地名中文名生成
- **游牧双体系** —— 六级草原勋爵 + 长生天眷，与东方体系并行
- **家族谱牒 / 继承改朝 / 附庸宣称 / 战争网关** 等 15 个子系统
- **全面中文化** —— 界面、图标与本地化资源

## AI 史官（可选功能）

填入大模型 API Key 后，可生成皇帝盖棺长评、实录野史、断代史、帝王本纪。

- **不接入也能玩**：全部玩法不依赖大模型，走本地模板
- **隐私**：API Key 只保存在你自己电脑的 `.runtime/llm.json`，Mod 不上传任何数据

接入方式见包内《大模型接入新手教程.md》。

## 运行要求

- WorldBox v0.51.2（build 549）
- [NeoModLoader](https://github.com/WorldBoxOpenMods/ModLoader) 模组加载器（创意工坊可订阅）
- 本 Mod 以**源码模式**分发，由 NeoModLoader 在本地编译，无需预编译 DLL

## 安装

1. 订阅创意工坊中的 NeoModLoader
2. 启动一次游戏让加载器创建 `Mods` 目录，然后退出
3. 将本 Mod 文件夹放入游戏目录下的 `Mods` 文件夹
4. 重新启动游戏

若游戏「设置 → 实验模式」已启用，初始界面会出现「模组列表」按钮，可在其中直接开关本 Mod。

## AI 内容披露

本 Mod 的「AI 史官」功能调用第三方大模型 API 生成历史文本，生成内容可能存在事实性偏差，请勿作为史实参考。Mod 的玩法框架、代码与美术资源均由 Zhulu Team 人工编写。
