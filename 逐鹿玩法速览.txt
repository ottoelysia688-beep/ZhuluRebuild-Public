# 东方与游牧等级
国力提升可晋级（取城、增人口）
东方：邑 → 子 → 伯 → 侯 → 公；受天命后为天命国
游牧：部族 → 大部 → 部盟 → 汗国 → 大汗庭；受长生天眷后建立王庭

# 天命与长生天眷
东方受命：国力≥40 · 净礼治≥8 · 独立国 · 国祚≥15年
游牧受眷：国力≥40 · 净汗威≥8 · 独立国 · 国祚≥15年
两套天命彼此独立，同一体系同时只能有一个持有国
东方天命国君主称皇帝；游牧王庭君主称天可汗
天命/天眷影响稳定与忠诚，数值档位相同
游牧合格国家发起争夺长生天眷谋划的概率较高，资格门槛不变

# 种族体制
人类固定东方文化，兽人固定游牧文化
其他智慧种族由世界规则确定默认体制，可在“种族体制”窗口修改
修改只影响该种族以后新建、叛乱转正或异体系篡位后的国家；现有国家不变
普通继承不改变体制；叛乱成功按新王种族，篡位按篡位者种族转换

# 系统功能
东方科举 / 游牧选贤：沿用相同轮次、评分和录取数值，授予各自身份特质
东方朝廷 / 游牧汗庭官制：沿用相同席位和任官数值，显示各自官名
东方国策 / 游牧政策：沿用相同效果、开销和等级门槛，只替换体系称谓
东方党争 / 游牧部族争斗：沿用相同机制与数值，显示各自派系名称
邦交纵横：附庸朝贡、互不侵犯、和约、宣称战争
地方官制：东方长吏 / 游牧百户长、千户长、万户长
东方保留谥号、庙号与年号；游牧使用王庭与天可汗称谓
礼治 / 汗威分别作为两套天命的资格数值
家族传承
战争类型（宣称、附庸、独立、全面、争夺天命/天眷）
叛乱期间使用临时叛军体制，转正后才启用正式等级、官制、政策、选拔和党争
注意：城市太少可能出现永恒王朝
         一般100年后才会战争常态化
